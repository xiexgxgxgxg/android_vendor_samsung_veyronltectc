# Vendor blobs — Samsung W2017 (SM-W2017 / veyronltectc)

> **STATUS: WORK IN PROGRESS — blobs extracted, tree not buildable/bootable yet.**
> The blobs come from the last official firmware (Android 6.0.1) and are far older
> than LineageOS 18.1 expects. Expect shims (camera HAL1, SecRIL, audio) to be
> needed before anything works.

## Source

| | |
|---|---|
| Firmware | `W2017KEU1ARG1` (CTC, China Telecom) |
| Build | `MMB29M` / Android 6.0.1 / security patch 2018-06-01 |
| Fingerprint | `samsung/veyronltectc/veyronltectc:6.0.1/MMB29M/W2017KEU1ARG1:user/release-keys` |
| Files | 894 (vendor/**, `lib{,64}/hw` HALs, Samsung/RIL/audio system libs), ~268 MB |

`proprietary-files.txt` is generated from this image and carries sha1 pins; the
files under `proprietary/` are the actual blobs.

## Refreshing

From the device tree directory:

```bash
./extract-files.sh /path/to/system_root   # or "adb"
./setup-makefiles.sh                       # regenerates veyronltectc-vendor.mk
```

`veyronltectc-vendor.mk` in this repo was generated by the same rules and can be
regenerated the same way.

## Known gaps

* No `android.hardware.*@1.x` HIDL implementations — 6.0.1 shipped pre-Treble HALs;
  the device tree will need shims or an older API target.
* Camera blobs are HAL1 (`libmmcamera_*`, chromatix data) — not usable as-is on 18.1.
* `libsec-ril.so` is the Samsung 6.0.1 RIL; 18.1 expects radio@1.4 + secbridge.
